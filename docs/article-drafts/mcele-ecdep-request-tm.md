## Knowledge content

As a **Training Manager**, use this procedure in **MCeLE** to review and recommend or deny a student's enrollment request for either of these ECDEP seminars:

- **5500 — Sergeants School Seminar Program**
- **6800 — SNCO Leadership School Seminar**

To process the request:

1. Sign in, open the left-hand navigation menu, and select **Administration**.
2. From the expanded menu, select **Requests**.
3. On the **Manage Requests** page, set the filters to **TYPE: Course Enrollment**, **REGION: All**, and **STATUS: All Active**. The page automatically refreshes to update the request table.
4. Locate the student whose request you want to process. Select **Course enrollment** to the left of their username.
5. Review the request and ensure all fields are properly completed.
6. Scroll down and expand **Request file list**. Confirm that both **NAVMC Form 11580** and the **prerequisite certification** are present. In some cases, the prerequisite certificate is bundled inside the form.
7. Expand **Decision** and make your selection. Add your comments in the provided text field.
8. Select **Recommend** or **Deny** to complete your action on the request.

If you experience issues while processing enrollment requests, contact the **Helpdesk** for assistance.
